# 部署指南：三种落地方式

| 方式 | 适合谁 | 能用的功能 | 门槛 |
|---|---|---|---|
| **A. 在线体验版**（静态网页） | 学生课前预习、课堂上机、快速试用 | 表格 Q-Learning 训练与回放、决策解说、价值传播、人机 PK、概念速查、实验任务链接 | 只需浏览器 |
| **B. 本地完整版**（一键启动） | 教师备课、做多种子对照实验 | 全部功能（含 PPO/DQN、AI 奖励设计师、实验对比、课程学习） | 安装 Python + Node.js |
| **C. 机房 / 课程服务器** | 一个班在局域网内共用 | 全部功能 | 一台电脑当服务器 |

## A. 在线体验版：发布到 GitHub Pages（免费）

1. 把本仓库推送到 GitHub（仓库名例如 `gewu-rl`）；
2. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**；
3. 推送到 `main` 分支后，`.github/workflows/pages.yml` 自动构建并发布（也可在 Actions 页面手动运行），地址为 `https://<用户名>.github.io/gewu-rl/`。

> 注意：GitHub 免费账号仅公开仓库支持 Pages。

也可以手动构建后放到任何静态网站（Gitee Pages、单位网站、对象存储等）：

```bash
cd app
npm ci
VITE_STATIC=1 npm run build      # Windows PowerShell：$env:VITE_STATIC="1"; npm run build
# 把 app/dist/ 整个目录上传即可；支持放在子路径（如 /gewu-rl/）下
```

`VITE_STATIC=1` 表示直接进入浏览器模式，不再探测后端。浏览器模式中的训练算法与后端 `gridworld_edu` 一致
（`tests/test_browser_engine.py` 在 4 个预设 × 10 个种子上校验），需要后端的功能会显示说明与启动方式。

## B. 本地完整版：一键启动

- **Windows**：双击 `start.bat`
- **macOS / Linux**：`./start.sh`

脚本会检查 Python 与 Node.js；首次运行自动创建虚拟环境、安装依赖（需联网，约 5–10 分钟），
然后启动后端（8000 端口）与前端（3000 端口）并打开浏览器。手动启动方式见 README。

## C. 机房 / 课程服务器（局域网共享）

在一台电脑上：

```bash
pip install -r requirements.txt
cd app && npm ci && npm run build && cd ..
# 后端监听局域网地址
python -m uvicorn main:app --app-dir backend --host 0.0.0.0 --port 8000
```

前端生产构建产物 `app/dist/` 需要与后端同源访问（`/api`、`/ws` 由同一地址提供）。最简单的做法是在服务器上运行开发服务器并开放局域网：

```bash
cd app && npm run dev -- --host 0.0.0.0 --port 3000
```

学生在浏览器访问 `http://<服务器 IP>:3000`。注意：

- 平台不收集个人信息；训练记录保存在服务器的 `backend/runs/`，可定期清理；
- 后端为教学用途设计，未做用户鉴权，**请只在校园内网使用，不要直接暴露到公网**；
- 大模型 API Key 仅在单次请求中使用、不落盘；不配置时 AI 奖励设计师使用内置规则引擎。
