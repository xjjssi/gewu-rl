## 一、概念测试（前测、后测各做一次，题目相同）

**Q1.** ε-greedy 策略中 ε=0.1，某格只有一个方向的 Q 值最高。该方向被选中的概率是：
A. 10%　B. 90%　C. 92.5%　D. 100%　　（答案：C，0.1/4 + 0.9）

**Q2.** 表格 Q-Learning 训练初期，Q 值为正的格子通常最先出现在：
A. 起点附近　B. 终点附近　C. 随机分布　D. 所有格子同时出现　　（答案：B）

**Q3.** 关于势函数奖励塑形 F = γΦ(s′) − Φ(s)，正确的说法是：
A. 会改变最优策略　B. 不改变最优策略，可能加快学习　C. 只对深度强化学习有效　D. 会让 Q 值全部变为正数　　（答案：B）

## 数据录入模板（供教师统计）

用 Excel 等工具录入为 CSV，第一行为表头（与 `tools/survey_template.csv` 一致）：

```
id,pre_q1,pre_q2,pre_q3,post_q1,post_q2,post_q3,sus1,sus2,sus3,sus4,sus5,sus6,sus7,sus8,sus9,sus10,d1,d2,d3
```

概念题填所选字母（A/B/C/D），其余填 1–5 的整数。统计命令：

```bash
python tools/analyze_survey.py 你的数据.csv
```

输出：前后测平均正确题数与提升、每题正确率变化、SUS 平均分（0–100，按标准算法：奇数题得分−1、偶数题 5−得分，求和×2.5）、
三项教学功能平均分。统计结果可直接写进技术报告的"用户试用"部分。
