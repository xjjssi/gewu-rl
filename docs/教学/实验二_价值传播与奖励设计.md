# 实验二：价值传播与奖励设计（45 分钟）

## 学习目标

1. 通过"价值传播动画"理解 TD 学习：终点奖励经 TD 目标 r + γ·max Q(s′) 一格一格向回传播（Bellman 方程的自举）；
2. 理解折扣因子 γ 对"远见"的影响；
3. 理解势函数奖励塑形（PBRS）为什么能加快学习，又为什么不改变最优策略。

## 实验设置

- 迷宫：**大迷宫 10×10**；算法：**表格 Q-Learning**。

## 步骤

### 第 1 步：看价值如何"流回"起点（15 分钟）

1. 回合数 500，默认参数训练；
2. 在"训练实时视图"打开 **Q 值热力图**，点 **"价值传播动画"**：热力图按回合播放，色标以 0 为中心（蓝 = 正价值，白 = 0，橙 = 负值），
   各回合颜色可直接比较；下方提示框给出当时有多少格子已有正价值。

**记录**：正价值格子从终点附近出现，到覆盖起点，大约经过了 ____ 回合。

### 第 2 步：有限预算下的奖励塑形（15 分钟）

1. 回合数改为 **150**，关闭"势函数塑形"，训练并播放价值传播动画；
2. 打开"势函数塑形（PBRS）"，其余不变，再训练、再播放。

### 第 3 步：折扣因子 γ（15 分钟）

回合数恢复 500，把 **γ** 从 0.99 改为 **0.8**，训练后对比热力图：离终点远的格子颜色深浅有何变化？

## 预期现象（5 个种子实测，见 `backend/teaching_observations.py`）

| 配置 | 评估成功率 | 收敛回合 | 训练进行到 1/4 时正价值格子 |
|---|---|---|---|
| 500 回合，γ=0.99（基线） | 100% | 约 50 | 约 37 / 64 |
| 150 回合，无塑形 | 100% | 约 30 | **约 11 / 64** |
| 150 回合，开启 PBRS | 100% | 约 22 | **约 53 / 64** |
| 500 回合，γ=0.8 | 100% | 约 51 | 约 26 / 64 |

## 讨论题与参考答案

1. **为什么价值是从终点"向外"扩散，而不是同时出现在所有格子？**
   参考：只有终点给出大的正奖励。一个格子的 Q 值要变成正，需要它的下一格 s′ 已经有正价值（TD 目标里的 γ·max Q(s′)）；
   所以价值只能一步一步向回传递——这正是 Bellman 方程"用后继状态的估计来更新当前估计"（自举）的含义。
2. **开启 PBRS 后，价值地图扩散快了很多，成功率却一样。塑形改变了什么、没改变什么？**
   参考：PBRS 按"离终点更近了多少"给额外奖励 F = γ·Φ(s′) − Φ(s)，相当于提前告诉智能体方向，所以学得更快；
   而 Ng 等（1999）证明这种形式的塑形不改变最优策略。技术报告 5.3（2）给出了 20 种子的正式对照：两组成功率均为 100%，开启塑形收敛更快、贪心策略更稳定。
3. **γ=0.8 时，远处格子的颜色为什么更浅？** 参考：每往回传一格，价值乘以一次 γ；γ 越小衰减越快——"远见"越短。
4. **（拓展）如果把终点奖励改成 0，只保留每步 −0.01 的代价，价值地图会怎样？** 鼓励学生动手试，再解释。
