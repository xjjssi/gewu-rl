## 教师如何布置

1. 在平台上搭好迷宫、设好参数，点右上角 **"分享实验任务"**，写一句任务说明，复制链接发给学生；
2. 学生打开链接即得到完全相同的实验设置，页面顶部显示任务说明；
3. 课后让学生提交实验记录表（各指导书末尾）与问卷；问卷数据可用 `tools/analyze_survey.py` 一键统计。

## 指导书中的"预期现象"从哪里来

均为实测：`python backend/teaching_observations.py` 在 5 个种子上复现每组配置的成功率、收敛回合、
探索占比与价值地图覆盖情况。不同种子的具体数值会有小幅波动，课堂上请以"趋势"为准。
