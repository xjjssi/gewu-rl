# 实验三：人机 PK——你和强化学习谁更会走迷宫（45 分钟）

## 学习目标

1. 比较人与 RL 在同一状态下的决策依据：人靠观察和先验知识，表格 Q-Learning 只靠试错积累的 Q 值；
2. 理解"一方探索、一方寻优"时的探索与利用权衡；
3. 在迷雾模式中体会：当人也看不见地图时，同样必须探索——这正是 RL 面对的处境。

## 实验设置

- 迷宫：**单障碍 6×6** 或 **多障碍 8×8**；Q-Learning 默认参数。

## 步骤

### 第 1 步：明牌对局（15 分钟）

1. 进入"人机 PK"，点"① 训练 RL 对手"，选择 **训练完成的 RL**，点"② 开始 PK"；
2. 每一步先选"🎯 寻优 / 🎲 探索"和理由，再按方向键出招；右侧会揭晓 RL 在**同一格**的选择，并按四种情况给出解释；
3. 走到终点后看结算，并在下表记录四种情况各出现几次。

### 第 2 步：换一个爱探索的对手（10 分钟）

选择 **新手 RL**（ε 约 0.94）再来一局，对比"都寻优"情况的出现次数。

### 第 3 步：迷雾对局（20 分钟）

打开 **迷雾模式**（只看得见走过的格子和撞过的墙），对手选"训练完成的 RL"，再来一局。
注意你在什么时候开始主动选择"探索"。

## 讨论题与参考答案

1. **明牌时你几乎每步都在"寻优"，迷雾中呢？为什么？**
   参考：明牌时你有整张地图（相当于拥有环境模型），可以直接规划；迷雾中没有模型，只能先探索再利用——与无模型 RL 相同。
2. **双方都"寻优"却选了不同方向，可能的原因有哪些？**
   参考：两个方向在 RL 看来 Q 值几乎相同（可能都是最短路）；或你看得见地图而 RL 只能凭经验；或对手训练不足（新手 RL）。
   右侧解释会给出双方所选方向的 Q 值，用来判断是哪一种。
3. **你走一局就到了终点，RL 却需要几十上百回合才能稳定到达，这公平吗？**
   参考：人有视觉、"墙不能穿过"等先验知识，RL 从零开始、每一步都要试。这正是样本效率问题，也是基于模型的 RL、迁移学习等方向要解决的问题。
4. **生活中哪些决策更像"迷雾对局"？** 例如：刚进入一个新城市、新课程、新工作。
